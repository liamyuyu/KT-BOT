# Sprint 5 概览

> **Sprint 5: 对话管理与用户体验优化**
>
> 📅 **周期**: 2026-01-29 ~ 2026-02-28 (31天)
> 🎯 **目标**: v0.3.0 发布 - 完整的用户体验和部署优化
> ⭐ **故事点**: 34 points

---

## 🎯 核心目标

Sprint 5 聚焦于**用户体验提升**和**部署优化**，完善知识库问答系统的基础功能，为生产环境部署做准备。

### 三大核心价值

1. **📚 对话管理** - 让用户能够管理和回顾历史对话
2. **📤 文档上传** - 支持用户添加私有文档到知识库
3. **🔍 引用优化** - 提供清晰的答案来源追溯

---

## 📦 功能清单

### Story 5.1: 对话历史管理 (10 points) ⭐ 核心功能

**为什么重要**: 用户需要查看和管理历史对话，回顾之前的问答内容

**核心功能**:
- ✨ 对话自动保存
- ✨ 对话列表和搜索
- ✨ 对话重命名和删除
- ✨ 对话导出（Markdown/JSON/PDF）
- ✨ 继续之前的对话

**技术实现**:
- PostgreSQL 持久化（conversations + messages 表）
- 12 个 REST API 端点
- 对话标题自动生成（关键词提取 + LLM）
- 全文搜索支持
- 多格式导出器

**预估工作量**: 5-6 天

---

### Story 5.2: 文档上传增强 (8 points) ⭐ 核心功能

**为什么重要**: 用户需要将私有文档纳入知识库

**核心功能**:
- ✨ 多格式支持（PDF、DOCX、TXT、MD、HTML）
- ✨ 批量上传（拖拽、多文件）
- ✨ 实时上传进度
- ✨ 自动文档解析和索引
- ✨ 元数据编辑

**技术实现**:
- 增强文档解析器（PyPDF2、python-docx、pdfplumber）
- 异步上传管理器
- SSE 实时进度推送
- 文件验证和大小限制
- 并发处理（最多 5 个文件）

**预估工作量**: 4-5 天

---

**预估工作量**: 3-4 天

### 数据库 Schema

```sql
-- 新增表
CREATE TABLE conversations (
    id UUID PRIMARY KEY,
    user_id VARCHAR(255),
    title VARCHAR(500),
    created_at TIMESTAMP,
    updated_at TIMESTAMP,
    message_count INTEGER,
    metadata JSONB,
    is_deleted BOOLEAN
);

CREATE TABLE messages (
    id UUID PRIMARY KEY,
    conversation_id UUID REFERENCES conversations(id),
    role VARCHAR(20),
    content TEXT,
    contexts JSONB,
    citations JSONB,
    created_at TIMESTAMP,
    model_name VARCHAR(100),
    token_count INTEGER,
    metadata JSONB
);

-- 索引
CREATE INDEX idx_conversations_user_created ON conversations(user_id, created_at DESC);
CREATE INDEX idx_conversations_title ON conversations USING gin(to_tsvector('simple', title));
CREATE INDEX idx_messages_conversation ON messages(conversation_id, created_at);
```
